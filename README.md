# DIGICLOAK Website

This is the official static website for DIGICLOAK – a multi-ISP enabled IT Hardware, Infrastructure, and Service Solutions provider.

### 🌐 Hosted on GitHub Pages
Live at: `https://<your-github-username>.github.io/digicloak-site/`

---

### 📁 Structure

- `index.html` – Landing page
- `services.html` – Service listings (connectivity, cloud, infra, etc.)
- `about.html` – Company mission and background
- `contact.html` – Contact form (Formspree)
- `partners.html` – Tier-1/2 vendor ecosystem
- `assets/css/styles.css` – All styling
- `assets/js/main.js` – Animations, smooth scrolls, interactivity

---

### 🚀 How to Deploy

1. Unzip this folder
2. Push to a GitHub repository
3. Go to Repository Settings → Pages → Source → `main` branch `/ (root)`
4. Access your site at: `https://<your-username>.github.io/<repo-name>/`
